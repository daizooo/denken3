# 実装計画：1級土木施工管理技士（第一次検定）の追加

- 作成日: 2026-11-10
- ステータス: v0（着手用の計画。§2 のデータ取得元は利用者の判断待ち）
- 必読: `CLAUDE.md`、`docs/design/licensehub-expansion.md`（社労士で作ったテキスト演習の基盤。本計画はその再利用）

---

## 1. 目的

LicenseHub に 2 つ目の資格として「1級土木施工管理技士 第一次検定」（`exam_id='doboku1'`）を追加し、
過去問（問題文・選択肢・正答・解説）をテキストで解いて ○×記録・FSRS 復習を回せるようにする。
社労士の機能・データは壊さない（追加のみ）。

### 非目標

- 第二次検定（記述式）。
- 社労士側のロジック変更。
- 第三者サイトからの自動一括取得（§2 参照）。

## 2. データ取得元（要判断・最優先）

利用者の希望は「過去問ドットコム（https://1dobokusekou.kakomonn.com/）から問題・解答・解説を取得」。
2026-11-10 時点の確認結果:

| 項目 | 状態 |
|---|---|
| kakomonn.com への接続 | **このクラウド環境のネットワーク設定で遮断**（DNS 解決不可）。利用規約も本文を開けず未確認 |
| 解説の権利 | 解説は同サイトの著作物。全件を複製して DB・リポジトリに保存するのは転載にあたる可能性が高い（推測。規約未確認） |
| 問題文・正答の公式公表 | 試験問題・正答番号は指定試験機関（全国建設研修センター）のホームページで公表（公表期間は1年。山形県の案内資料に記載、二次情報）。jctc.jp もこの環境からは遮断 |

このため、取得経路は次の案を提案する（推奨は A）。

- **A（推奨）: 公式PDF＋AI解説＋参照リンク**
  - 問題文・選択肢・正答: 公式の試験問題PDF・正答番号（利用者がブラウザで保存して添付。社労士 PR-D と同じ運用）。
  - 解説: Claude が根拠（示方書・法令条文等）を付けて作成し、`explanation_source='ai'`・`explanation_verified=false` で保存。
  - 過去問ドットコムは**問ごとの参照URLだけ**を持ち、解説は同サイトで開いて読む（本文は複製しない）。
- B: 利用者が問題集（書籍）のスクリーンショットを渡し、書き起こす（社労士 §14 と同じ）。
- C: 過去問ドットコムの本文取得。**利用規約で私的な複製・自動取得が許されていることを利用者が確認し、ネットワーク許可を追加した場合に限り**検討する。その場合も本文はリポジトリに置かず DB のみ（社労士 §4.1 と同じ）。

## 4. 試験制度（要確認：公式PDFの受領後に確定）

- 第一次検定は四肢択一のマークシート。問題A・問題B、選択解答（例: ○問中○問）と必須問題（施工管理法・応用能力）がある。
- 出題数・解答数・合格基準（原則60%、応用能力の基準点）は**年度により変わりうるため、本計画では固定しない**。
  公式PDF・受検案内で確認し、`src/data/doboku1/index.ts` の設定値1か所に置く。
- 次回試験（令和9年度）の日程は未確認。`denken_exam_plans` の初期行は日程判明後に投入（データ投入のみ、DDLなし）。

## 5. データモデル（追加のみ）

- 既存 `lic_questions` / `lic_items` は `exam_id` 列を持たないため、**ID 接頭辞で名前空間を分ける**。

| 種別 | 形式 | 例 |
|---|---|---|
| 問 | `D1_{年度}_{A|B}_{問番号2桁}` | `D1_R07_A_15` |
| 肢 | `D1_{年度}_{A|B}_{問番号}_{肢}` | `D1_R07_A_15_C`（肢1〜4 → A〜D、`label_raw` に元番号） |

- 列の割当: `format='taku'`、`source='honshiken'`、`scored_subject`=区分（土木一般/専門土木/法規/共通工学/施工管理法 など）、`study_subject`=学習分野ID。
- 「適当でないもの／適当なものを選べ」は全肢の `truth` を導出（`truth_source='derived'`）。
  応用能力の形式（複数正答など）が既存 `answer_spec` で表せない場合のみ、`src/domain/license.ts` に kind を末尾追加する。
- 参照URL（案A）は `lic_items` に列が無いため、`law_note` 等の流用はせず、必要になった時点で `ADD COLUMN source_url text`（新規 migration、番号はコミット直前に採番）。

## 6.5 図解解説の方針（2026-11-10 利用者指示：図解中心）

- 確定事項: 問題・正答は公式（全国建設研修センターの試験問題・正答肢。PDF は利用者が提供）。解説は Claude が作成し、図解を中心にする。
- 公式の公表は**令和8年度分のみ**（公表期間1年。2026-11-10 に https://www.jctc.jp/mondai/ で確認）。過去年度は別途入手手段が要る。
- 解説の構成（1問単位）: ①論点（1〜2文）→ ②図 → ③肢チェック（各肢 ○/× と一言）。肢の一言は既存 `lic_items.explanation`、図は問単位で持つ。
- 図の型（試作で検討中。推奨は「型＋自由SVG」）:
  - 型1 構造図: 断面・三相図など形が固有のもの → 自由SVG
  - 型2 数値・ルール図: 規定値・回数・時間の決まり → データから自動描画
  - 型3 フロー図: 契約・施工手順 → データから自動描画
  - （追加候補）比較表: 工法・機械の特徴の比較 → データから自動描画
- 保存先（案）: `lic_questions` に `explain jsonb` を ADD COLUMN（新規 migration、番号はコミット直前に採番、追加のみ）。SVG は `<img src="data:image/svg+xml,…">` で表示し、スクリプトを実行させない。
- 品質: 正答は必ず公式の正答肢と一致させる（不一致は保存しない）。根拠（示方書・約款・準則の条番号）を確認するまで `explanation_verified=false`。
- 問題文中の図（擁壁の配筋図など）は試験問題の一部。リポジトリや公開フォルダには置かず、非公開ストレージ（`denken-problems` と同形のRLS）に置く。
