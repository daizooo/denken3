# 2級建設業経理士「入門」（前提知識のノート＋基礎ドリル）

- 作成日: 2026-11-13
- ステータス: v1（経理の入門 8テーマ・24問を実装）
- 関連: `docs/design/kenkei2.md`（過去問の取り込み・解答画面）

## 1. 目的

初学者がいきなり過去問を解くと、解説に出てくる用語（未成工事支出金・差額補充法・原価比例法など）が分からず手が止まる。
過去問の前に「読む（入門ノート）→ 手を動かす（基礎ドリル）」の段階を置く。

## 2. 仕様

| 項目 | 内容 |
|---|---|
| 置き場所 | 資格「2級建設経理」の科目タブの**先頭**に「入門」。章 ＝ テーマ（学習順）、問 ＝ 基礎ドリル |
| 入門ノート | ドリルの解答画面の上に表示。未読なら開いた状態。「読んだ」で次からは畳む（端末の localStorage `kk2:primer:read`。DB は使わない） |
| 基礎ドリル | 過去問と同じ解答画面・採点（仕訳＝`journal`、金額＝`amount`）。満点で正解。採点後に解説を表示 |
| 記録 | 過去問と同じ経路（`denken_reviews`・`exam_id='kenkei2'`・FSRS）。**復習の予定に載る**（過去問の数が少ないため、利用者の判断で載せる） |
| ID | `K2_P_<テーマ>_<2桁>`。`K2_` で始まるので AnyItemSolver が経理の画面へ振り分ける。過去問の ID とは `parseKk2Id` / `parsePrimerId` で区別 |
| 本文の置き場 | リポジトリ（`src/data/kenkei2/primer/`）。Claude 作成で第三者の著作物を含まないため。DB の `kk2_questions` は読まない |
| 正確性 | すべて Claude 作成・根拠未確認。ノートに根拠を書き、その旨を画面に表示 |

## 3. テーマ（学習順）

1. 簿記の基本（5要素と仕訳） 2. 建設業に特有の勘定科目 3. 工事原価の流れ 4. 決算整理（貸倒引当金・減価償却）
5. 材料の払出単価 6. 配賦（部門費・予定配賦） 7. 工事収益の計上（進行基準） 8. 精算表の読み方

## 4. 追加のしかた（コンフリクト最小化）

- テーマ1つ ＝ `src/data/kenkei2/primer/topics/<id>.ts` 1ファイル。`primer/index.ts` の `PRIMER_TOPICS` の**末尾**に1行足す。
- 既存テーマの `id` とドリルの並びは変えない（ID ＝ 記録のキー。並べ替えると記録が別の問に付く）。ドリルは末尾に足す。
- 勘定科目群（`symbols.ts`）は A〜Z を使い切っている。科目を増やすときはテーマ側で別の科目群を持たせる拡張が必要。
