# 1級土木「入門」（前提知識のノート＋○×一問一答）

- 作成日: 2026-11-13
- ステータス: v1（解答画面＋重要4分野。残りの分野は後続 PR で末尾に追加）
- 関連: `docs/design/kenkei2-primer.md`（同じ考え方の経理版）、`docs/design/doboku1-ichiji.md`（過去問の取り込み・解答画面）

## 1. 目的

初学者がいきなり過去問を解くと、解説の前提用語（最適含水比・ブリーディング・ヒービング・x̄-R 管理図など）が分からず手が止まる。
過去問の前に「読む（入門ノート）→ ○×で確かめる（一問一答）」の段階を置く。1級土木は暗記中心のため、経理の「計算ドリル」ではなく ○× にする。

## 2. 仕様

| 項目 | 内容 |
|---|---|
| 置き場所 | 資格「1級土木」の科目タブの**先頭**に「入門」。章 ＝ 学習分野（`src/data/doboku1/categories.ts` の18分野の id を使う）、問 ＝ ○× 一問一答 |
| 章の並び | §3 の着手順（＝ registry の並び）。18分野の定義順ではない |
| 入門ノート | 解答画面の上に表示（経理と同じ `PrimerNoteView` を使う。既読の記録キーだけ `d1:primer:read` に分ける） |
| ○×一問一答 | 記述を読み「○／×」を選び「自信あり／迷いあり」で決定、または「分からない」。決定で正誤・理解度（A/B/C）を記録し解説を出す。誤タップは「修正」で取り消す |
| 記録 | 過去問と同じ経路（`denken_reviews`・`exam_id='doboku1'`・FSRS）。**復習の予定に載る**（過去問が少ないため、利用者の判断） |
| 試行の形 | `selected: [1]`＝○、`[2]`＝×（社労士の肢モードと同じ）。`correct` は選択と正答の一致 |
| ID | `D1_P_<分野id>_<2桁>`（例 `D1_P_dokou_01`）。`D1_` で始まるので AnyItemSolver が `Doboku1ItemSolver` へ振り分ける。過去問 ID（`D1_R08_A_01`）の解析 `dbkCategoryOfId` は `R\d{2}` を要求するため入門 ID には undefined を返し、衝突しない。`parseD1PrimerId` で区別 |
| 本文の置き場 | リポジトリ（`src/data/doboku1/primer/`）。Claude 作成で第三者の著作物を含まない。DB の `dbk_questions` は読まない（DB 変更なし） |
| 正確性 | すべて Claude 作成・根拠未確認。分野ごとに根拠（示方書・法令・指針の名称）を書き、ノートと解説に「根拠未確認」と表示 |

## 3. 分野の着手順（学習順）

配点（必須か・出題数）と初学者のつまずきやすさで決める。

| 順 | 分野 | 理由 |
|---|---|---|
| 1 | 土工 | 土木一般（15問中12問）の柱。土質用語が他分野（基礎工・品質管理）の前提 |
| 2 | コンクリート | 土木一般で出題数最多。用語（スランプ・水セメント比・養生）が品質管理・構造物の前提 |
| 3 | 品質管理 | 問題Bの必須（施工管理・応用能力）。管理図・ヒストグラムは初学者がつまずく |
| 4 | 安全管理 | 問題Bの必須で出題数最多。安衛則の数値（高さ・幅）を覚える必要 |
| 5 | 工程管理 | 問題Bの必須。ネットワーク（クリティカルパス）は計算の前提知識が要る |
| 6 | 施工計画 | 問題Bの必須。仮設・建設機械の選定 |
| 7 | 基礎工・土留め | 土木一般。ヒービング・ボイリングなど現象名の区別 |
| 8 | 基礎（土質・力学・水理） | 令和6年度〜必須5問。計算問題の前提 |
| 9 | 法規 | 12問中8問。労基法・安衛法・建設業法の数値 |
| 10 | 環境保全・建設副産物 | 問題Bの必須 |
| 11 | 共通工学 | 問題Bの必須（測量・契約・設計・機械） |
| 12〜18 | 道路・舗装 → 河川・砂防 → 鋼橋・コンクリート構造物 → ダム・トンネル → 鉄道・シールド → 海岸・港湾 → 上下水道・その他 | 専門土木は34問中10問の選択。得意分野を選べるよう後回し |

PR 分割: 第1弾＝解答画面＋順1〜4、第2弾＝順5〜8、第3弾＝順9〜11、第4弾＝順12〜18。

## 4. 追加のしかた（コンフリクト最小化）

- 分野1つ ＝ `src/data/doboku1/primer/topics/<分野id>.ts` 1ファイル。`primer/index.ts` の `D1_PRIMER_TOPICS` の**末尾**に1行足す（import も末尾）。
- 既存分野の `id` と問の並びは変えない（ID ＝ 記録のキー）。問を足すときは末尾に足す。
- 分野 id は `DOBOKU1_CATEGORIES` の id と同じにする（テストで検査）。
