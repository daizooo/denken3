## 3. 照合の方法

1. e-Gov 法令API（v2）で、出題範囲の法令（法・施行令・施行規則・関係法令・安衛の特別規則 約85本）の改正履歴（`/api/2/law_revisions/{法令ID}`。未施行の改正を含む）を取得した。
2. 各法令について、**2025-04-11 時点の版**と **2027-04-01 時点の版**の本文（`/api/2/law_data/{版ID}`）を取得し、条・別表・附則ごとに差分を取った。途中の版も取得して、各条の改正の施行日と改正法令を特定した（一部の版は 404 のため飛ばした）。改正法の附則（平成16年改正法附則第2条・年金機能強化法附則など）は、e-Gov が被改正法令に収録している版で照合した。
3. 差分のあった条に関わる肢は新旧の条文を読み比べて判定し、差分のない条に関わる肢は「2027/4/1までの改正なし」として `ok` にした。条番号は条文の語句検索で確かめた。
4. 告示で決まる取扱い（選定療養）は、厚生労働省の公表資料（法令等データベース・案内ページ）で 2027/4/1 時点の内容を確かめた。
5. 注記（`law_note`）は `[判定 2026-10-14 基準日 2026-04-10] 確認済み|要確認|除外: 根拠（改正内容。e-Gov照合・教材未確認）` の1行を**追記**した（問題誤りの公表・自動判定の注記は残す）。統計・白書の肢は「教材未確認」のみ、告示を公表資料で確かめた肢は「厚労省の公表資料で確認。教材未確認」。

## 4. 限界（判定に含まれないもの）

- **通達・行政手引・認定基準・統計・白書**は e-Gov の対象外。法令（根拠条文）に改正がないことだけを確かめた。統計の肢は調査年次を明示した問のため、法改正で正誤は変わらない。告示は選定療養（KH_08_E・KH_10_C）と特別加入の給付基礎日額（RS_04_A：改正の公表なし）だけを公表資料で確かめた。
- **2027年版の教材は未確認**（全肢の注記に「教材未確認」）。教材と食い違った場合は教材を優先する（§9）。
- e-Gov に未反映の改正（公布直後のもの・特別加入団体の要件の省令など）や、施行日が政令で未確定の改正は差分に現れない。2027年4月の法令基準日の公告後に、`docs/license-law-review.md` §6 の再照合を行う。
- 年度改定される数値（保険料率・延納額など）を使う肢は、問題文が年度（令和7年度）を明示しているものだけを `ok` にした（`R07_T_RS_09_B`・`D`・`E`、`R07_T_KO_05_A`）。
- 文言の一部（引用される機関名・条番号・用語）が改正で変わったが論点の正誤が変わらない肢（`R07_T_RK_08_B`・`R07_T_KH_02_B`・`R07_T_KH_07_A`・`R07_S_RI_C` など）は `ok` にし、変わった文言を注記に残した。

```sql
SELECT count(*) AS n,
  count(*) FILTER (WHERE i.law_status = 'ok') AS ok,
  count(*) FILTER (WHERE i.law_status = 'review') AS review,
  count(*) FILTER (WHERE i.law_status = 'excluded') AS excluded,
  count(*) FILTER (WHERE i.law_note LIKE '%[判定 2026-10-14 基準日 2026-04-10]%') AS judged,
  md5(string_agg(i.id || '|' || i.law_status || '|' || COALESCE(i.law_note, ''), ',' ORDER BY i.id)) AS md5
FROM lic_items i WHERE i.user_id = (SELECT id FROM auth.users) AND (i.id LIKE 'R07\_%\_<採点科目>\_%');
```

戻すとき（本番では実行していない。自動判定の注記がある肢は review、ない肢は unchecked に戻し、判定の行だけを消す。R08 の判定にも同じ日付の注記があるため、対象は `R07_` に限る）:

```sql
BEGIN;
DO $$ BEGIN
  IF (SELECT count(*) FROM auth.users) <> 1 THEN RAISE EXCEPTION '利用者が1人ではありません'; END IF;
END $$;
UPDATE lic_items
SET law_status = CASE WHEN law_note LIKE '%[法改正の自動判定]%' THEN 'review' ELSE 'unchecked' END,
    law_note = NULLIF(btrim(regexp_replace(law_note, '\n?\[判定 2026-10-14 基準日 2026-04-10\][^\n]*', '', 'g'), E' \n'), '')

  AND id LIKE 'R07\_%'
  AND law_note LIKE '%[判定 2026-10-14 基準日 2026-04-10]%';
COMMIT;
```
