# ステルス（擬装）モード

会社PCなど、周囲に画面を見られる環境で学習内容を同僚に気づかれないための「業務ソフト擬装」機能。
学習ロジックには一切干渉せず、`src/features/stealth/` 配下で自己完結している（App を被せるだけの構成）。

## 使い方

### 起動
- **会社PC**：`?work=1` を付けたURL（例 `https://<app>/?work=1`）をブックマークして開く。
  開いた瞬間から擬装モードＯＮ＋パニックカバー（ダミー文書）表示で始まる。
- 一度 `?work=1` で開くとブラウザに記憶され、次回はパラメータ無しでも擬装モードで起動する。
- **擬装のON/OFF切替**：`Ctrl + Alt + H`（自宅などで通常表示に戻すとき用）。

### 隠す（パニックカバー）
擬装モード中、以下で即座にダミー文書エディタが全面に被さる（学習内容が隠れる）。
- **マウスカーソルを画面の左上隅へ**移動する
- **他のウィンドウ／アプリに切り替える**（ウィンドウが非アクティブになる）と自動で被さる
- **別タブへ移動**した場合も自動で被さる

### 戻す（復帰）
- ダミー文書の**左上の文書アイコンをダブルクリック**すると学習画面へ戻る。
- 覗かれている間は、ダミー文書の本文はそのまま入力できるので、文字を打って「作業中」を装える。

## 擬装中の見た目
- ブラウザのタブ名は「無題 - ドキュメント」、ファビコンも地味な文書アイコンに変わる。
- アプリ全体の彩度を落とし、青いブランド色を消して社内ツール／文書ソフト風の無彩色寄りにする。
- ヘッダーの資格名は「取材メモ」に、試験カウントダウンや「今日の復習◯問」などの
  一目で資格学習と分かる文言は非表示／無害な表記に差し替える。ログイン画面も同様。

## 制約
年度別（CBT）・分野別の問題本体は電験王ページの切り抜き画像のため、大きく表示すると擬装しきれない。
そこは彩度ダウンで目立ちにくくしつつ、上記のパニックカバーで一発で隠す運用で対応する。

## 設定値
発動する画面隅・許容ピクセル・擬装時のタイトル等は `src/features/stealth/config.ts` に集約。
