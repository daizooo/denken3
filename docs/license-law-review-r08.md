## 3. 照合の方法

1. e-Gov 法令API（v2）で、出題範囲の法令（法・施行令・施行規則・関係法令 約70本）の改正履歴（`/api/2/law_revisions/{法令ID}`。未施行の改正を含む）を取得した。
2. 各法令について、法令基準日（2026-04-10）時点の版と 2027-04-01 時点の版の本文（`/api/2/law_data/{版ID}`）を取得し、**条・別表・附則ごとに差分**を取った。途中の版も取得して、各条の改正の施行日と改正法令を特定した。
3. 差分のあった条に関わる肢は新旧の条文を読み比べて判定し、差分のない条に関わる肢は「2027/4/1までの改正なし」として `ok` にした。
4. 注記（`law_note`）は `[判定 2026-10-14 基準日 2026-04-10] 確認済み|要確認: 根拠（改正内容。e-Gov照合・教材未確認）` の1行を**追記**した（問題誤りの公表・自動判定の注記は残す）。

## 4. 限界（判定に含まれないもの）

- **通達・行政手引・認定基準・統計**は e-Gov の対象外。法令（根拠条文）に改正がないことだけを確かめた。統計の肢は調査年次を明示した問のため、法改正で正誤は変わらない。
- **2027年版の教材は未確認**（全肢の注記に「教材未確認」）。教材と食い違った場合は教材を優先する（§9）。
- e-Gov に未反映の改正（公布直後のもの）や、施行日が政令で未確定の改正は差分に現れない。2027年4月の法令基準日の公告後に、`docs/license-law-review.md` §6 の再照合を行う。
- 年度改定される数値（支給停止調整額・保険料額など）を使う肢は、問題文が年度を明示しているものだけを `ok` にした（`R08_S_KO_E`）。

## 5. 実行した SQL

[`license-law-review-r08.sql`](license-law-review-r08.sql) に全文（`license-law-review.md` §4 のひな形どおり。8バッチ）。各バッチは次の順に流した。

1. 確認の SELECT（対象の肢の件数と状態。利用者が1人であること）
2. UPDATE（`BEGIN` … `COMMIT`）
3. 結果の SELECT（件数・判定の注記の数・`md5(string_agg(id||'|'||law_status||'|'||law_note))` をローカルの期待値と照合）

ローカルの PostgreSQL（本番と同じ R08 の行を再現）で `EXPLAIN`（`lic_items_law_status` を使用）と2回実行（2回目は全バッチ `UPDATE 0`、内容の md5 も同一）を確かめてから本番に流した。本番の結果の md5 は全バッチでローカルの期待値と一致した。

| バッチ | 肢 | 実行前（review / unchecked） | 実行後（ok / review） |
|---|---:|---|---|
| R08_RK | 55 | 26 / 29 | 55 / 0 |
| R08_RS | 55 | 20 / 35 | 54 / 1 |
| R08_KY | 55 | 30 / 25 | 55 / 0 |
| R08_KH | 55 | 26 / 29 | 54 / 1 |
| R08_KO | 55 | 47 / 8 | 55 / 0 |
| R08_KN | 55 | 31 / 24 | 55 / 0 |
| R08_IP | 50 | 23 / 27 | 50 / 0 |
| R08_RISI（RI・SI） | 10 | 5 / 5 | 10 / 0 |

戻すとき（本番では実行していない。自動判定の注記がある肢は review、ない肢は unchecked に戻し、判定の行だけを消す。ローカルで、戻した結果が判定前の状態と全行一致し、2回流しても同じで、反映SQLを再び流すと判定後と一致することを確認済み）:

```sql
BEGIN;
DO $$ BEGIN
  IF (SELECT count(*) FROM auth.users) <> 1 THEN RAISE EXCEPTION '利用者が1人ではありません'; END IF;
END $$;
UPDATE lic_items
SET law_status = CASE WHEN law_note LIKE '%[法改正の自動判定]%' THEN 'review' ELSE 'unchecked' END,
    law_note = NULLIF(btrim(regexp_replace(law_note, '\n?\[判定 2026-10-14 基準日 2026-04-10\][^\n]*', '', 'g'), E' \n'), '')
WHERE user_id = (SELECT id FROM auth.users)
  AND id LIKE 'R08\_%'
  AND law_note LIKE '%[判定 2026-10-14 基準日 2026-04-10]%';
COMMIT;
```
