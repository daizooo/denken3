## 3. 照合の方法

1. e-Gov 法令API（v2）で、出題範囲の法令（法・施行令・施行規則・関係法令・安衛の特別規則 87本）の改正履歴（`/api/2/law_revisions/{法令ID}`。未施行の改正を含む）を取得した。
2. 各法令について、**2024-04-12 時点の版**と **2027-04-01 時点の版**の本文（`/api/2/law_data/{版ID}`）を取得し、条・別表・附則（被改正法令に収録された改正法の附則を含む）ごとに差分を取った。途中の版も取得して、各条の改正の施行日と改正法令を特定した（健保法・船員保険法の一部の版は 404 のため飛ばした。施行日の特定にだけ影響し、2027-04-01 の版との差分には影響しない）。
3. 差分のあった条に関わる肢は新旧の条文を読み比べて判定し、差分のない条に関わる肢は「2027/4/1までの改正なし」として `ok` にした。引用した条に正誤に関わらない改正（引用条項・刑名・機関名の整理など）があった肢は、その改正内容を注記に書いた。条番号は条文の語句検索で確かめた。
4. 注記（`law_note`）は `[判定 2026-10-14 基準日 2026-04-10] 確認済み|要確認|除外: 根拠（改正内容。e-Gov照合・教材未確認）` の1行を**追記**した（問題誤りの公表・自動判定の注記は残す）。統計・白書・告示の記述の肢は「教材未確認」のみ。

## 4. 限界（判定に含まれないもの）

- **通達・行政手引・認定基準・告示・統計・白書・社会保障協定**は e-Gov の対象外。法令（根拠条文）に改正がないことだけを確かめた。統計・白書の肢は調査年次・年版を明示した問のため、法改正で正誤は変わらない。
- **2027年版の教材は未確認**（全肢の注記に「教材未確認」）。教材と食い違った場合は教材を優先する（§9）。
- e-Gov に未反映の改正（公布直後のもの・特別加入団体の要件の省令など）や、施行日が政令で未確定の改正は差分に現れない。2027年4月の法令基準日の公告後に、`docs/license-law-review.md` §6 の再照合を行う。
- 文言の一部（引用される機関名・条番号・用語）や、設例の前提にある数値（`R06_T_KO_06_A` の賃金 88,000円など）が改正で変わったが、肢の論点の正誤が変わらない肢は `ok` にし、変わった内容を注記に残した。要件そのものを列挙した肢（`R06_T_KH_02_A`）は review にした。

  count(*) FILTER (WHERE i.law_status = 'ok') AS ok,
  count(*) FILTER (WHERE i.law_status = 'review') AS review,
  count(*) FILTER (WHERE i.law_status = 'excluded') AS excluded,
